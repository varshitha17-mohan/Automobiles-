# 🚗 Automobile World

## About the Project
Automobile World is a website that provides information about automobiles, car parts, vehicle showrooms, and repair services.

## Features
- 🏠 Home page
- 🔧 Automobile parts information
- 🚘 Vehicle showroom
- 🛠️ Service and repair details
- 📅 Online service booking
- 📩 Contact page

## Technologies Used
- HTML
- CSS
- JavaScript
- Python Flask
- SQLite Database

## Backend
Python Flask handles service booking requests, and SQLite stores booking information.

## Project Goal
To provide users with an easy way to explore automobiles and request vehicle servicing online.
