ABOUT THE GEARBOX

A gearbox helps transmit engine power to the wheels. It provides different gear ratios to help a vehicle move efficiently under different driving conditions.

03 / TRANSMISSION SYSTEM

POWER THROUGH EVERY GEAR

The gearbox is part of the vehicle's transmission system. It changes the relationship between engine speed and wheel speed to help the vehicle accelerate and travel at different speeds.

KEY FUNCTIONS

  • Transfers power through the transmission system.
  • Provides different gear ratios.
  • Helps the vehicle accelerate efficiently.
  • Supports reverse movement in many vehicles.

TYPES OF GEARBOXES

⚙

MANUAL GEARBOX

The driver selects gears manually using a gear lever and clutch in most manual cars.

🚘

AUTOMATIC GEARBOX

Selects suitable gear ratios automatically according to driving conditions.

🔧

CVT GEARBOX

A continuously variable transmission changes ratios smoothly across a range instead of using fixed stepped gears.
